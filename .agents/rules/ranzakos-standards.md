# RanzakOS Core Rules
@/.github/copilot-instructions.md

## Context
These rules are mandatory for all development tasks in RanzakOS. They ensure consistency in UI, i18n, and project structure.

## Activation
- **Mode**: Always On
- **Description**: Applies the project-specific coding standards defined in the copilot-instructions file to all Gemini/Antigravity interactions.

## Additional Constraints
- **TypeScript**: Strictly avoid `any`. Use proper interfaces or `unknown` with type guards.
- **Components**: Use glassmorphism and modern aesthetics as per the `web_application_development` guidelines.
- **Commits**: Always use conventional commits (e.g., `feat:`, `fix:`, `refactor:`).
